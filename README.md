# АБСУРД НА ПОДКЛАДЕ 🧵

E-commerce платформа для лимитированных дропов и кастомной одежды.  
Проект разрабатывается как пет-проект для портфолио и одновременно является боевым сайтом для бренда.

## 🛠 Стек технологий
- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion
- **UI Components:** shadcn/ui (Base UI, Nova preset)
- **Backend / API:** Next.js API Routes, Server Actions
- **Database:** PostgreSQL, Prisma ORM
- **Hosting:** Vercel (планируется)

## 🚀 Как запустить локально
1. `npm install`
2. `npm run dev`
3. Открой http://localhost:3000
